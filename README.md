# CI Agro Helper

## О проекте

CI Agro Helper — цифровой помощник для агрономов и фермеров, помогающий эффективно управлять земельными участками, планировать севооборот и получать агрономические рекомендации на основе данных о полях, истории культур и климатических условиях.

Система предоставляет веб-интерфейс с интерактивной картой полей, инструментами для ведения истории культур, анализа спутниковых данных и получения персональных рекомендаций по севообороту.

## Основные возможности

### 🗺️ Управление полями
- Интерактивная карта с отрисовкой границ полей
- Хранение информации о каждом участке (площадь, регион, статус)
- Карточки полей с заметками и показателями

### 📊 История культур
- Ведение журнала истории культур по каждому полю
- Навигация по сезонам и годам
- Аналитика по культурам и их последовательности

### 🌾 Рекомендации по севообороту
- Персональные рекомендации на основе истории поля
- Учет почвенных и климатических условий
- Ранжированный список культур с обоснованиями
- Каталог агрономических правил севооборота
- Фильтрация по приоритету, требованиям к почве и климату

### 🛰️ Спутниковая аналитика
- Интеграция с Planet Labs для оценки NDVI/NDWI/MSI
- Визуализация спутниковых индексов на карте
- Мониторинг состояния посевов

### 🌤️ Погодный ассистент
- Прогноз погоды для вашего региона
- Агрономические рекомендации на основе климатических условий
- Учет рисков заморозков и засухи

### 💰 Экономический модуль
- Поиск культур в справочнике
- Экономические ориентиры и справочная информация

### 🔐 Безопасность
- Регистрация и авторизация пользователей
- Защищенное хранение данных
- Персональные аккаунты с профилями

## Быстрый старт

### Требования

- Docker и Docker Compose
- 4+ GB свободной оперативной памяти
- Доступ в интернет (для загрузки образов)

### Установка и запуск

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/Kxqusos/ci-agro-helper.git
   cd ci-agro-helper
   ```

2. **Создайте файл `.env` в корне проекта:**
   ```bash
   POSTGRES_DB=app
   POSTGRES_USER=app
   POSTGRES_PASSWORD=app
   DATABASE_HOST=postgres
   DATABASE_PORT=5432
   DATABASE_URL=postgresql+asyncpg://app:app@postgres:5432/app
   RECOMMENDATIONS_DATABASE_URL=postgresql+asyncpg://app:app@postgres:5432/app
   JWT_SECRET=change-me-in-production
   ```

   ⚠️ **Важно**: Для production окружения сгенерируйте безопасный секрет:
   ```bash
   openssl rand -hex 32
   ```
   Используйте полученное значение для `JWT_SECRET`.

3. **Запустите систему:**
   ```bash
   docker compose up -d --build
   ```

4. **Проверьте статус сервисов:**
   ```bash
   docker compose ps
   ```

5. **Откройте приложение в браузере:**
   ```
   http://localhost:3000
   ```

6. **Создайте демо-пользователя (опционально):**
   ```bash
   docker compose run --rm auth python seed_demo_user.py
   ```
   Email: `demo-agronom@local`  
   Password: `Demo123!`

### Остановка системы

```bash
docker compose down
```

## Использование

### Регистрация и вход

1. Откройте приложение в браузере
2. Перейдите на страницу авторизации
3. Зарегистрируйте новый аккаунт или войдите с существующими данными

### Работа с полями

1. На главной странице откройте карту полей
2. Добавьте новое поле, нарисовав его границы на карте
3. Заполните информацию о поле (название, площадь, регион)
4. Сохраните поле

### Ведение истории культур

1. Выберите поле на карте или из списка
2. Перейдите в раздел "История"
3. Добавьте запись о культуре: год, сезон, название культуры
4. Система автоматически сохранит историю

### Получение рекомендаций

1. Выберите поле для планирования
2. Укажите целевой сезон и год
3. При необходимости настройте фильтры:
   - Лимит количества рекомендаций
   - Требования к органическому веществу почвы
   - Климатические условия
4. Нажмите "Получить рекомендации"
5. Просмотрите ранжированный список культур с обоснованиями
6. Изучите детали каждой рекомендации: приоритет, соответствие почве, необходимые действия

### Просмотр правил севооборота

1. Перейдите в раздел "История" → вкладка "Правила"
2. Просмотрите каталог агрономических правил
3. Используйте фильтры для поиска нужной культуры
4. Изучите информацию о:
   - Интервалах возврата культур
   - Хороших и плохих предшественниках
   - Требованиях к почве
   - Влиянии на питательные вещества

### Спутниковая аналитика

1. Выберите поле на карте
2. Откройте раздел спутниковых данных
3. Выберите тип индекса (NDVI, NDWI, MSI)
4. Просмотрите визуализацию на карте

### Погодный прогноз

1. Перейдите в раздел "Погода"
2. Выберите регион или используйте автоматическое определение
3. Просмотрите прогноз на ближайшие дни
4. Изучите агрономические рекомендации на основе погодных условий

## Структура проекта

Проект состоит из следующих основных компонентов:

- **`frontend/`** — веб-приложение на Next.js с интерактивной картой и интерфейсом управления
- **`auth/`** — сервис авторизации и управления пользователями
- **`recommendations/`** — сервис рекомендаций по севообороту
- **`fields/`** — сервис управления полями (в разработке)
- **`crop_history/`** — сервис истории культур (в разработке)
- **`weather/`** — сервис погодных данных (в разработке)
- **`economy/`** — экономический модуль (в разработке)
- **`reference/`** — справочный модуль (в разработке)

## Технологии

- **Frontend**: Next.js, React, TypeScript, Tailwind CSS, Leaflet
- **Backend**: Python, FastAPI, PostgreSQL с PostGIS
- **Контейнеризация**: Docker, Docker Compose
- **Внешние API**: WeatherAPI, Planet Labs, ESRI World Imagery

## Конфигурация

### Переменные окружения

Основные переменные для работы системы:

- `POSTGRES_DB`, `POSTGRES_USER`, `POSTGRES_PASSWORD` — параметры базы данных
- `DATABASE_URL` — строка подключения к PostgreSQL
- `JWT_SECRET` — секретный ключ для подписи токенов авторизации
- `AUTH_SERVICE_URL` — URL сервиса авторизации (для внутренней коммуникации)
- `RECOMMENDATIONS_SERVICE_URL` — URL сервиса рекомендаций
- `WEATHER_API_KEY` — ключ API для получения погодных данных (опционально)
- `PLANET_API_KEY` — ключ API Planet Labs для спутниковых данных (опционально)

Подробный список переменных и их описания находятся в файлах `.env.example` в соответствующих директориях.

## Развертывание в production

### Требования

- Сервер с Docker и Docker Compose
- Nginx Proxy Manager (для проксирования и SSL)
- Минимум 4 GB RAM, 20 GB свободного места

### Шаги развертывания

1. **Подготовьте сервер:**
   - Установите Docker и Docker Compose
   - Настройте firewall (откройте только необходимые порты)

2. **Настройте переменные окружения:**
   - Скопируйте `.env.example` в `.env`
   - Сгенерируйте безопасные секреты для `JWT_SECRET` и `POSTGRES_PASSWORD`
   - Настройте URL сервисов для Docker network

3. **Запустите сервисы:**
   ```bash
   docker compose up -d --build
   ```

4. **Настройте Nginx Proxy Manager:**
   - Создайте Proxy Host, указывающий на `http://localhost:3000`
   - Включите SSL через Let's Encrypt
   - Настройте WebSocket поддержку

5. **Проверьте работоспособность:**
   - Откройте приложение через настроенный домен
   - Проверьте авторизацию и основные функции

⚠️ **Безопасность**: 
- Используйте сильные пароли для базы данных
- Генерируйте уникальные секреты для каждого окружения
- Настройте HTTPS через Nginx Proxy Manager
- Регулярно делайте резервные копии базы данных

# Правила севооборота — Документация данных

Этот каталог содержит формализованные агрономические правила севооборота для использования в сервисе рекомендаций.

## Файлы

- **`crop_rotation_rules.json`** — основной файл данных с правилами севооборота
- **`crop_rotation_rules_schema.json`** — JSON Schema для валидации структуры данных
- **`crops_seed.json`** — снимок таблицы `crops`, экспортированный из основного файла
- **`crop_rotation_rules_seed.json`** — снимок таблицы `crop_rotation_rules`
- **`soil_requirements_seed.json`** — снимок таблицы `soil_requirements`
- **`README.md`** (этот файл) — документация и правила работы с данными

## Структура данных

### Верхний уровень

```json
{
  "version": "1.0.0",           // Версия данных (semver)
  "updated": "2025-01-14",      // Дата последнего обновления
  "sources": [...],              // Массив источников
  "botanical_families": {...},   // Справочник ботанических семейств
  "crops": [...]                 // Массив правил для культур
}
```

### Источники (`sources`)

Каждый источник должен содержать:

```json
{
  "id": "unique_id",           // Уникальный идентификатор
  "title": "Название",         // Полное название источника
  "authors": "Автор(ы)",       // Авторы (опционально)
  "year": 2024,                // Год публикации
  "url": "https://...",        // URL (опционально)
  "isbn": "...",               // ISBN для книг (опционально)
  "doi": "..."                 // DOI для статей (опционально)
}
```

### Ботанические семейства (`botanical_families`)

Справочник содержит информацию о семействах растений:

```json
{
  "poaceae": {
    "name_ru": "Злаковые (Мятликовые)",
    "name_latin": "Poaceae",
    "common_pests": ["Злаковая тля", ...],
    "common_diseases": ["Корневая гниль", ...]
  }
}
```

**Поддерживаемые семейства:**
- `poaceae` — Злаковые (Мятликовые)
- `fabaceae` — Бобовые
- `asteraceae` — Астровые (Сложноцветные)
- `solanaceae` — Пасленовые
- `brassicaceae` — Крестоцветные (Капустные)
- `apiaceae` — Зонтичные
- `cucurbitaceae` — Тыквенные
- `amaranthaceae` — Амарантовые

### Правила для культур (`crops`)

Каждая культура содержит:

#### Основные поля

```json
{
  "crop_id": 1,                      // ID из frontend/src/data/crops.json
  "crop_name": "Пшеница мягкая",     // Русское название
  "crop_latin": "Triticum aestivum", // Латинское название
  "botanical_family": "poaceae",     // Ключ семейства
  "rotation_rules": {...}            // Правила севооборота
}
```

#### Правила севооборота (`rotation_rules`)

##### 1. Интервал возврата (`return_interval_years`)

```json
{
  "min": 2,          // Минимальный срок возврата (лет)
  "recommended": 3   // Рекомендуемый срок возврата (лет)
}
```

##### 2. Хорошие предшественники (`good_predecessors`)

```json
[
  {
    "crop_id": 19,                    // ID культуры или "family:название"
    "rating": "excellent",            // "excellent" или "good"
    "reason": "Обогащение азотом",    // Причина совместимости
    "sources": ["source_id_1"]        // Ссылки на источники
  }
]
```

**Типы `crop_id`:**
- Число (напр. `19`) — конкретная культура из `crops.json`
- Строка `"family:название"` — целое семейство (напр. `"family:fabaceae"`)

**Значения `rating`:**
- `"excellent"` — отличный предшественник (бобовые, пары, сидераты)
- `"good"` — хороший предшественник

##### 3. Допустимые предшественники (`acceptable_predecessors`)

Культуры, допустимые при соблюдении условий:

```json
[
  {
    "crop_id": 6,
    "conditions": "При достаточном внесении удобрений",
    "sources": ["source_id"]
  }
]
```

##### 4. Плохие предшественники (`bad_predecessors`)

```json
[
  {
    "crop_id": 1,
    "reason": "Общие вредители и болезни",
    "sources": ["source_id"]
  }
]
```

##### 5. Несовместимые семейства (`incompatible_families`)

Массив ключей семейств, с которыми нельзя чередовать:

```json
["poaceae", "fabaceae"]
```

##### 6. Требования к почве (`soil_requirements`)

```json
{
  "ph_range": {
    "min": 6.0,
    "max": 7.5,
    "optimal": 6.5
  },
  "soil_type": ["суглинистая", "черноземная"],
  "organic_matter": "средняя",    // "низкая", "средняя", "высокая"
  "drainage": "хороший"            // "плохой", "средний", "хороший"
}
```

**Типы почвы:**
- `"легкая"` — песчаные, супесчаные
- `"средняя"` — суглинистые
- `"тяжелая"` — глинистые
- `"суглинистая"` — средние суглинки
- `"песчаная"` — песчаные
- `"черноземная"` — черноземы

##### 7. Влияние на питательные вещества (`nutrient_impact`)

```json
{
  "nitrogen": "истощение",          // Влияние на азот
  "phosphorus": "нейтральное",      // Влияние на фосфор
  "potassium": "истощение",         // Влияние на калий
  "organic_matter": "нейтральное"   // Влияние на органику
}
```

**Возможные значения:**
- `"сильное_истощение"` — культура сильно истощает элемент
- `"истощение"` — культура истощает элемент
- `"нейтральное"` — нейтральное влияние
- `"обогащение"` — культура обогащает почву
- `"сильное_обогащение"` — культура сильно обогащает (напр. бобовые для азота)

##### 8. Дополнительные поля

```json
{
  "notes": "Дополнительные замечания",
  "data_confidence": "высокая"  // "высокая", "средняя", "низкая", "отсутствует"
}
```

## Правила обновления данных

### 1. Добавление новой культуры

1. Убедитесь, что культура есть в `frontend/src/data/crops.json`
2. Определите ботаническое семейство
3. Соберите информацию из **минимум 2-3 надежных источников**
4. Заполните все обязательные поля
5. Укажите минимум 3 хороших и 3 плохих предшественника (или обоснование их отсутствия в `notes`)
6. Добавьте ссылки на источники в поле `sources`
7. Укажите `data_confidence`

### 2. Обновление существующих данных

1. Проверьте актуальность источников (год публикации, репутация)
2. При изменении данных добавьте новый источник в массив `sources`
3. Обновите поле `updated` в корне JSON
4. Укажите причину изменений в комментарии коммита

### 3. Добавление нового ботанического семейства

1. Используйте латинское название в нижнем регистре (напр. `poaceae`)
2. Укажите русское и латинское названия
3. Добавьте основные вредители и болезни семейства
4. Убедитесь, что семейство используется хотя бы одной культурой

### 4. Валидация данных

Перед коммитом всегда валидируйте JSON:

```bash
# Установите ajv-cli
npm install -g ajv-cli

# Валидация
ajv validate -s crop_rotation_rules_schema.json -d crop_rotation_rules.json
```

Также можно использовать Python:

```python
import json
import jsonschema

with open('crop_rotation_rules_schema.json') as f:
    schema = json.load(f)

with open('crop_rotation_rules.json') as f:
    data = json.load(f)

jsonschema.validate(data, schema)
print("✓ Валидация успешна")
```

## Критерии качества данных

### Минимальные требования

Для каждой культуры должны быть указаны:

- ✅ Минимум 3 хороших предшественника
- ✅ Минимум 3 плохих предшественника
- ✅ Интервал возврата (min и recommended)
- ✅ Ботаническое семейство
- ✅ Список несовместимых семейств
- ✅ Ссылки на источники для всех предшественников

**Исключения:** Если для культуры невозможно найти 3 предшественника, это должно быть явно обосновано в поле `notes` с указанием причины (напр., "Редкая культура, данных недостаточно").

### Приоритеты источников

1. **Высокий приоритет:**
   - Учебники по агрономии (РГАУ-МСХА им. Тимирязева и др.)
   - Методические рекомендации НИИ
   - Научные статьи в рецензируемых журналах

2. **Средний приоритет:**
   - Справочники по растениеводству
   - Публикации агрономических порталов
   - Статьи практикующих агрономов

3. **Низкий приоритет:**
   - Любительские сайты
   - Форумы
   - Непроверенные источники

## Использование данных

### В сервисе рекомендаций

Данные используются для:

1. **Оценки качества предшественника** — алгоритм проверяет историю поля и рекомендует следующую культуру
2. **Проверки интервала возврата** — предупреждение, если культура возвращается слишком рано
3. **Анализа совместимости семейств** — блокировка посадки культур одного семейства подряд
4. **Учета требований к почве** — фильтрация культур по pH и типу почвы
5. **Расчета влияния на почву** — прогноз истощения/обогащения питательными веществами

### Примеры запросов

#### Найти хороших предшественников для пшеницы

```python
wheat = next(c for c in data['crops'] if c['crop_id'] == 1)
good_preds = wheat['rotation_rules']['good_predecessors']
excellent = [p for p in good_preds if p['rating'] == 'excellent']
```

#### Проверить, можно ли сажать томат после картофеля

```python
tomato = next(c for c in data['crops'] if c['crop_id'] == 109)
bad_preds = tomato['rotation_rules']['bad_predecessors']
potato_bad = any(p['crop_id'] == 47 for p in bad_preds)  # True
```

#### Получить все культуры семейства бобовых

```python
legumes = [c for c in data['crops'] if c['botanical_family'] == 'fabaceae']
```
